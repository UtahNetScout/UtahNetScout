### Featured Projects

#### [GoalieScout](https://github.com/UtahNetScout/GoalieScout)

An AI-assisted hockey scouting and analytics platform integrating multi-source
data ingestion, goalie performance analytics, SQLAlchemy persistence,
multi-provider LLM adapters, automated reporting, and command-line workflows.

- Product requirements and architecture spanning data ingestion through reports
- OpenAI, Anthropic, Ollama, and GitHub Copilot-assisted development
- GitHub Actions continuous integration
- 158 automated tests covering analytics, persistence, APIs, validation, and
  pipeline orchestration
- Explicit documentation of product hypotheses, limitations, and responsible use

#### [2026 Big Data Cup Goalie Analysis](https://github.com/UtahNetScout/2026-BIG-DATA-CUP-GOALIE-ANALYSIS)

An interpretable Python analytics pipeline that transforms frame-level hockey
tracking data into threat-conditioned goalie vulnerability insights and visual
decision-support outputs.

- Staged schema alignment, coordinate normalization, identity stabilization,
  event alignment, modeling, and visualization
- Dynamic vulnerability fields, rolling compasses, storyboards, and validation
  panels
- 27 automated tests with GitHub Actions continuous integration
- Measured mean threat-conditioning shift of 0.1392, with 94.49% of showcase
  frames shifting by at least 0.05
- Conservative documentation of evidence boundaries and model limitations
